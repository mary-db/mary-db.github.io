# Dietary Diversity as a Modifier of Multiple Micronutrient Supplementation's Effect on Low Birth Weight

**Published in:** American Journal of Clinical Nutrition (AJCN)
**Authors:** Mary de Boer, Andrew L. Thorne-Lyman, Abu Ahmed Shamim, 
Lee S-F Wu, Hasmot Ali, Saijuddin Shaikh, Keith P. West, Parul Christian

**Full text:** https://ajcn.nutrition.org/article/S0002-9165(25)00396-X/pdf
**Trial registration:** NCT00860470 (clinicaltrials.gov)

## Summary
This study examined whether maternal dietary diversity during pregnancy 
changes how effective multiple micronutrient supplementation (MMS) is 
at preventing low birth weight, using data from the JiVitA-3 trial in 
rural Bangladesh (n=19,160). We found that MMS had the strongest 
protective effect among women with the *least* diverse diets, suggesting 
supplementation may offer the most benefit to already vulnerable groups.

## Methods
- 10-item dietary diversity score (DDS) built from 7-day food frequency data
- Generalized estimating equations (log-binomial regression) to account 
  for cluster randomization
- Interaction between DDS and MMS tested for effect on low birth weight

## Code
Analysis script (`/code/analysis_script.R`) includes the regression 
models and interaction testing used to generate the paper's results.

## Data
Data are from the JiVitA-3 trial and are governed by a data use
